# Teras Rumah Kayu Restaurant Website

A full-stack restaurant website developed for Teras Rumah Kayu Restaurant. The website provides restaurant information, food menu presentation, online ordering, and payment features through a modern and responsive user interface.

## Features

- Restaurant information
- Food and menu presentation
- Online food ordering
- Shopping cart
- Order management
- Payment features
- Responsive website design
- User-friendly interface

## Technologies

- JavaScript
- HTML5
- CSS3
- Node.js
- REST API
- Database

## Tools

- Visual Studio Code
- Git & GitHub
- Figma

## Project Overview

This project is a restaurant website designed to provide customers with an easy way to explore the restaurant's menu, place food orders, and complete the payment process through an online platform.

The website focuses on providing a responsive, modern, and user-friendly experience across different screen sizes.
